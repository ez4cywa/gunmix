# GunMix 0.3.0 开火场景版：操作与开发交付

开发依据：output/pdf/MW4_M5_M2_M1_核验与开发规格.pdf。此版在现有 Windows WPF 软件上增加事件场景，不改变旧工程的默认渲染模式。原版未知业务谓词仍保留 unknown/partial，项目可明确配置触发与叠加规则。

## 运行与使用

运行 `app/publish-v0.3.0/GunMix.App.exe`，不需要另外安装 .NET。原 `app/publish` 保留。

1. 在主窗口导入武器声音目录。例如 `D:/_tiqu/Saluki/exported_files/mw4_beta/sounds/rex/wpn/ar_mike4`。多武器使用主窗口的武器切换，每个武器保留独立素材与配方。
2. 点击顶栏“开火场景…”，勾选启用事件场景。
3. “声音定义”页选择声音根 `D:/_tiqu/Saluki/exported_files/mw4_beta/sounds`，导入 `sndbanks/json/weapon_rex_ar_mike4_plr.all.json`。普通/消音、玩家/NPC 要选择各自 bank，不按同名 alias 合并。
4. 选中 `weap_rex_mike4_fire_plr_shot`，添加别名事件层。如果保留了旧 SHOT 层，请删除或关闭重复层，否则会同时播放。导入 bank 会登记引用 WAV，不会修改源文件。
5. 在“事件映射与关联”中调整 dB、延迟、音高比。每发用 EveryShot；普通发用 OrdinaryShot；末弹用 LastRound；释放用 Release；空仓用 DryFire；预动作和动作完成分别用 Prefire、CycleComplete。FCG/interrupt/prefire 候选新增时关闭，请选择正确触发后手动启用。
6. 如需采用 shot → swt → mech → lfe 候选叠加，点击添加全部候选关联，再逐条勾选所需关系。默认不执行 alias2。目标 dB 与延迟独立配置，不自动继承未知原版值。链末缺 WAV 会列出错误并阻止导出，不能用相似素材偷偷替换。
7. “场景”页设置 Auto、600 RPM、尝试数 6、弹药 30，释放帧留空。48 kHz 射击帧应为 0、4800、9600、14400、19200、24000；释放为 28800，余弹 24。Single=半自动，Burst=点射，Bolt=栓动/泵动。动作未就绪的按下不自动补射。
8. “事件、实例与证据”分别编译单发和连发，检查弹药、所选实例与诊断。末弹由扣弹前 ammo=1 判定，固定六发的最后一发不自动变成末弹。单发只尝试一次，但可播放显式启用的释放映射。
9. 应用后，在主窗口分别选择单发或连发试听；导出窗口独立选择单发、连发，保存 WAV。正常尾声用 NaturalTail；确需切断时选择 FadeOnRelease 或 StopOnRelease。尾部静音裁剪在完整混音之后进行。
10. 保存为 `.gunmix.json`。旧 schema 工程必须另存，不覆盖原文件。取消场景窗口不会写入草稿设置。

消音、视角、环境、距离字段会进入上下文快照和指纹。本版仅 ADS 文件名候选参与成员筛选；其他条件通过手选 bank/层实现，不声称已恢复引擎自动路由。ADS 缺候选时须明确允许普通素材回退。

## 高级输入

所有填写的帧以 48 kHz 为参考，在目标采样率下按比例转换。高级 JSON 用于多次扳机、动作就绪和同帧上下文切换；留空使用一次按下/释放。

```json
[
  { "frame": 0, "kind": 3 },
  { "frame": 14400, "kind": 2 },
  { "frame": 24000, "kind": 3 },
  { "frame": 38400, "kind": 2 }
]
```

kind：0=Ready，1=ContextChanged，2=TriggerUp，3=TriggerDown。上下文示例 `{ "frame": 0, "kind": 1, "context": { "ads": true, "suppressed": false, "perspective": "player", "environment": "outdoor", "distance": "near" } }`。同帧顺序为就绪、上下文、释放、按下、射击；零帧释放不射击。单发忽略高级多次按下序列。最长输入 60 秒。

## 交付与开发落点

| 规格 | 本版实现 |
|---|---|
| M5 证据 | EvidenceLedger 保留 confirmed/partial/unknown 与缺口；引用构建哈希；命令和实例可追踪；没有硬编码 Ghidra 地址 |
| M2 控制器 | FireScenario / FireController；弹药、末弹、空仓、半自动、自动、点射取消/完成、栓动就绪、多次扳机、上下文快照 |
| M2 统一渲染 | TimelineCompiler 生成实例计划；试听和导出均使用 MixKernel；释放时刻由控制器产生；层 voice limit 生成实例淡出 |
| M2 缓存与峰值 | 全输入及素材元数据哈希指纹；触发/种子/上下文改变失效；实际混合数据峰值；导出报告记录最终 WAV 峰值 |
| M1 定义 | bank 名和源 SHA 隔离作用域；稳定原始行与行 ID；保留未补零哈希与 raw JSON；未知 gain/pitch/weight/loop 为 null |
| M1 图执行 | 仅显式开启关系执行；路径环检测；深度限制；每个层每次触发的实例预算；重复射击产生独立实例；缺资产不借用 |
| GUI 与兼容 | 四页场景窗口、独立单发/连发、多武器、草稿应用/取消、旧工程另存迁移 |
| 输出 | WAV、recipe JSON、evidence-report JSON；实例清单及停止命令包含在两份报告中 |

工程主要新增代码在 `app/src/GunMix.Core/Fire`，GUI 在 `app/src/GunMix.App/Views/FireStudioWindow.*`。旧 SoundBankIndex 单参数 Lookup 保留动画兼容；新枪声流程使用 bank 作用域定义。CAST 读取改为 FileShare.Read，修复并行扫描遗漏。重复导出按递增后缀寻找空闲名称。

## 验证

验收目录 `output/development_validation_20261002` 包含实际 GUI 截图、mike4 单发/六发 WAV、配方及证据报告、可打开的 `mike4_event_scenario.gunmix.json` 和 TRX。示例工程只启用 SHOT 根；完整叠加需按步骤手动配置。

自动测试启用了真实素材路径。覆盖文档 12 个参考向量、3 类非法输入，多次扳机/上下文/动作门、末弹替换、循环/预算、bank 隔离/ADS、缺素材、指纹失效、停止/淡出、voice limit、峰值相消、迁移，以及实际 WPF 窗口至 WAV/报告的链路。GUI 集成比较了相同渲染计划的试听引擎浮点数据与输出 32-bit float WAV 的逐采样一致性；未把设备播放/人工听感视为已验收。

复查：设置 `GUNMIX_ASSETS_ROOT` 为素材根后，运行 `dotnet test app/tests/GunMix.Core.Tests/GunMix.Core.Tests.csproj`。没有该变量时真实素材用例不执行实际检查。

## 后续原版证据工作与当前边界

原规格中的上游标志位业务谓词、运行引用 +0x18 与 alias2 逐行绑定、FCG/interrupt 触发、真实 context/权重/gain/pitch/loop 字段仍未获得闭合证据。本版通过显式项目规则完成可用制作流程，不将这些条件标为已恢复。

图以候选关系表查看，事件与实例以表格查看；没有交互节点图或独立的事件时间轴。证据报告和实例日志为 JSON，可用于后续审计。项目覆盖当前保存为层/关联设置及 ruleOrigin，尚未提供逐覆盖作者、变更历史审计 UI。SourceIdentity 目前以源路径/SHA/bank/解析能力和引用构建哈希记录；未导出工具版本不推测。软件尚不执行游戏进程或自动采集游戏听感对照。

最终验收：153 项测试全部通过；Release 自包含发布成功，发布程序窗口启动检查结果见 release-smoke.json。完整测试结果见 tests/EZ4_DESKTOP-SSBSO2I_2026-10-02_11_03_08.trx。
